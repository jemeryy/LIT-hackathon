## Important discoveries and decisions
- SSO blocks WebFetch (403). Playwright on `https://sso.agc.gov.sg/Act/SCTA1984?ProvIds=pr5-,Sc-` returns
  the text. SCTA 1984 s 2, s 5 and the Schedule are quoted verbatim in `content/statutes.json`,
  retrieved 5 Sep 2026.
- Fixtures are on by default even with the key present (`USE_FIXTURES` defaults to 1). Set
  `USE_FIXTURES=0` for real calls. The first uvicorn run made one live call before this was fixed.
- Real-model dry runs (three, ~100 s each, about $0.10 each): the whole pipeline works live, every quote
  the model returns is matched back into our own OCR/PDF text. First run: the model dropped the nested
  `meta` object so every row scored weak, and it over-extracted (13 facts from six chat shots). Fixed by
  flattening the meta fields, inferring meta from the facts when the model skips them, capping at 3 facts
  per file, and giving the text prompts the dated events. Second run ranked the six keys 1-6 with
  strong/strong/medium/medium/medium/weak. Third run (92 s): same six keys ranked 1-6, story and
  500-character summary read correctly with the right dates, gate passes. Live order differs from the
  wireframe in one place (damage allegation ranks 4, move-out video 5) and the labels are wordier. Log:
  `builds/case-builder/data/dryrun_real3.log`, raw model replies in `data/llm_log.jsonl`.
- Recommendation: demo on fixtures (deterministic, matches the wireframe exactly). Say on stage: the
  parsing, quote matching, highlights, gate, ranking, exports are live; the model's reads are replayed
  from a saved run so the demo is repeatable. Keep the live path for Q&A (`USE_FIXTURES=0`, one minute).
- Grill decision 7 refinement stands (from-picture sets `needs_check`, not a weak cap).
- OpenRouter spend this session: $0.63 of the $15 cap (three dry runs plus stray live calls) (check `/api/v1/key`).
